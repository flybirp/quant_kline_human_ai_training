## 模型返回什么

正文只有一个标签，例如：

```
<score> N </score>
```

同时响应携带 logprobs（字母位置的 top-20 token 概率，实测形态示意）：

| 候选 token | 概率 | 归并字母 | φ 值 |
|---|---|---|---|
| `>N`（> 与字母常合并为单 token） | 0.91 | N | 14 |
| ` K` | 0.07 | K | 11 |
| ` Q` | 0.02 | Q | 17 |

连续分计算：R = 0.91×14 + 0.07×11 + 0.02×17 = 13.85 → 归一化 (13.85−1)/19 = **0.676**

（本笔 signal 子标准 3 次重复的实际均值 = 0.157，模型对「横盘中段介入」给了低分）
